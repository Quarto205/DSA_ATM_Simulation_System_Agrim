# ATM Simulator

Goal:
Build an enterprise-quality ATM Simulation System in Python.

Rules

- Follow SOLID principles.
- Follow OOP.
- Never generate God classes.
- Use layered architecture.
- Keep UI separate from business logic.
- Use dependency injection when appropriate.
- Every class should have a single responsibility.
- Prefer composition over inheritance.

Project Structure

app/
core/
services/
repositories/
models/
exceptions/
ui/
tests/

Features

✔ Login
✔ PIN Verification
✔ Deposit
✔ Withdraw
✔ Transfer
✔ Balance Inquiry
✔ Mini Statement
✔ Transaction History
✔ Admin Panel
✔ Card Blocking
✔ Daily Withdrawal Limit
✔ Persistence using SQLite

Coding Style

- Type hints
- Docstrings
- Black formatting
- Ruff linting
