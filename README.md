# ATM-Simulation-System
The project is an advanced console-based ATM and banking management system implemented using OOP, DSA, JSON persistence and GitHub collaboration. The original documents define the core modules: ATM, BankSystem, Account, Transaction, CashDispenser, FileManager, AuthManager and Admin.

An enterprise-inspired ATM Simulation System developed using **Object-Oriented Programming**, **Data Structures & Algorithms**, **SOLID Principles**, and **Design Patterns**.

---

## Features

- Secure Authentication
- Cash Withdrawal
- Cash Deposit
- Money Transfer
- Balance Inquiry
- PIN Change
- Mini Statement
- Receipt Generation
- ATM Cash Inventory
- Admin Dashboard
- JSON Data Persistence
- Transaction History
